# Veges 更新说明（2026 年 8 月 31 日）

1. 简化安装包市场配置：

   - 普通组件使用 `roots` 前缀，系统固定派生正式包和 CI 包目录；
   - 移除 `release_roots` 和 flat-file 包目录支持；
   - 依赖包继续使用独立的 `dependency_roots` 配置。

2. 增加页面种类元数据：

   - YAML 可定义页面种类的英文 code、稳定 key 和中文显示名；
   - 前端优先使用服务端返回的页面种类名称展示安装包分类。

3. 中间件自动发现：

   - 通过 `page_kinds.middleware.discovery.roots` 配置中间件父目录；
   - 自动发现每个根目录下的一级中间件目录，并按名称去重；
   - 保留环境变量作为旧配置的兼容回退。
